6GB 显存本地部署 ComfyUI + SD 1.5 + 动画生成全记录

Created2026-08-11|Updated2026-08-11|AI
|Post Views:

硬件与方案

RTX 4050 Laptop 6GB，试了一圈结论：SD 1.5 是 6GB 显存的最优解。SDXL/Flux/SD3 要么跑不动，要么 OOM 到崩溃。

最终选择了 ComfyUI Windows Portable + SD 1.5 底模 + AnimateDiff 运动模块，实现了文生图、图生图、文生视频、图生视频、视频插值五合一。

模型选择

模型 大小 风格
DreamShaper 8 2GB 艺术写实全能
Realistic Vision V5.1 2GB 照片级写实
SD 1.5 原版 4GB 备用

下载优先用国内源：ModelScope 下 SD 1.5 原版（4 分钟），hf-mirror.com 下社区模型（DreamShaper/Realistic Vision）。

坑与修复

  1. ComfyUI 0.31.0 Windows 后台 OSError — app/logger.py 的 write() 和 flush() 在非控制台环境崩溃，加 try/except OSError 修复
  2. AnimateDiff 与 DynamicVRAM 冲突 — 启动必须加 --cache-classic，同时修了 model_injection.py 和 sampling.py 的 ModelPatcher API
  3. Gitee 镜像版本过旧 — AnimateDiff Evolved 直接从 GitHub 拉新版
  4. SaveVideo codec 参数 — 动态 combo 类型需要传 h264 值

交互式工具 gen.py

写了个交互式菜单脚本，运行 python gen.py 选模式：

填提示词、选模型、调参数，自动调用 ComfyUI API 生成。另有 ui.py 提供浏览器操作面板。

动画生成

基于 AnimateDiff，每次生成 8 帧（6GB 限制），长视频自动分多段 + ffmpeg 拼接。支持：

  • 运动插值（8fps → 24/30/60fps 丝滑输出）
  • 段间衔接模式（同 seed / 重叠淡入淡出）
  • 图生视频（给张照片，AI 让它动起来）

总结

6GB 显存虽然紧张，但 SD 1.5 + 好底模 + AnimateDiff 这个组合足够玩出花。关键是选对模型（2GB 的 DreamShaper/Realistic Vision 比 4GB 原版好用）、优先国内下载源、启动参数用 --cache-classic。
